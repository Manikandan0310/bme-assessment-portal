Why upload happens like this

GitHub Pages only serves static files — there's no server to receive uploads live. So this tool converts your CSVs into plain JS/CSV files on your computer, which you then commit to the repository (or drag into GitHub's web uploader). Once committed, every student visiting the site sees the update immediately.
